Definitions and limits

relevance: Binary required-document IDs from the independent reference; exact versions are distinct IDs. No graded relevance labels are invented.

conditionalRetrieval: Only document-applicable episodes with recorded completed retrieval output. Explicit empty output after a requested search scores zero; unknown error stages and skipped searches are excluded and counted separately.

rankMetrics: Recall@6 = distinct relevant hits / required documents. MRR@6 uses the first relevant rank, with0 if none in6. nDCG@6 uses binary gains and ideal ordering of up to6 required documents. R3 managed raw ranking metrics are unavailable.

managedCoverage: R3 selected-document coverage measures the authorized documents selected through provider citations, not raw managed search recall or rank quality.

endToEnd: Fraction of all recorded document-applicable episodes that released an unblocked result whose actual authorized evidence included every required document. Errors and blocked outcomes count as failed delivery, without assigning unknown retrieval stages a zero retrieval score.

taxonomy: Multi-label observed conditions, not mutually exclusive causes. Structured fact mismatch may include semantic key, currency, entity, period or schema mismatch; it is not automatically an arithmetic error.

latency: Nearest-rank p50/p95 for all attempts and separately non-error outcomes (including blocks). Harness wall includes pacing/queue waits. Complete HTTP totals require durations for every provider attempt in the explicit per-call usage snapshot. Partial known subtotals have separate percentiles; entirely unknown or unverified legacy aggregates are excluded. No-call episodes are disclosed separately. Provider sums are not production latency.

  • Descriptive supplemental metrics on synthetic documents; no confidence intervals, causal claims, human citation-entailment judgments or publication-grade power are implied.
  • Conditional retrieval results can be selected by planner decisions and upstream failures. Read them alongside skipped/unknown counts and end-to-end delivery.
  • Required-document labels identify a reference evidence set, not an exhaustive set of every possibly relevant document.
  • An absent final episode record is not an observed failure. Compare these measured denominators with the main run manifest for planned/missing episodes.
  • Repeated episodes and paraphrases are clustered. Scenario-macro recall is also shown; no episode independence is assumed.
  • The current runner may discard intermediate state after an exception. Unknown-stage errors cannot diagnose retrieval quality.
